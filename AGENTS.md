# Crewhelm agent instructions

For changes intended for commit, follow `.agents/skills/crewhelm-delivery/SKILL.md`.

Preserve unrelated changes, use the domain language in `CONTEXT.md`, and never weaken
`docs/security/invariants.md`.

Crewhelm pull requests use `.github/PULL_REQUEST_TEMPLATE.md` instead of any broader or global PR
description format.

Do not push, merge, deploy, publish, create external resources, or perform destructive actions
without explicit user authorization.
